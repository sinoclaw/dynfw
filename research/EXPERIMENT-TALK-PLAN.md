# 小模型「会说话」实验 —— 跑前锁定判据（2026-09-11）

## 目标
用我们的架构（v6 `fused_fw_fw_cycle`）训一个小模型，**验证它能不能生成连贯的英语文本**（「会说话」）。

## 为什么用 TinyStories 语料（不是我们的 UltraX 网页语料）
依据 arXiv:2305.07759：GPT-2 small (125M) 在**完整英文**上「生成不了几个连贯词」，
但 **<10M 参数 + 1 层 transformer** 在 **TinyStories**（3-4 岁词汇合成语料）上能写多段连贯故事。
→ **门槛是「数据熵 ÷ 模型容量」，不是参数绝对值。**
→ 用简化语料才能让「架构」成为唯一变量，否则两个架构都只会输出垃圾，测不出东西。

## 对轰口径（跑前锁死）
| 维度 | 设定 |
|---|---|
| **语料** | TinyStories（train/valid 同一份固定子集） |
| **tokenizer** | GPT-2 BPE，vocab=50257（**两边完全相同**） |
| **结构参数** | **≈4.72M（两边对齐）** |
| **深度 n_layer** | **6（两边相同）** |
| **token 预算** | 固定步数 × batch × T（两边逐 step 完全相同） |
| **seed** | 0（可加 1/2 加固） |
| **优化器/调度** | 两边完全相同（AdamW + warmup + cosine） |
| **唯一变量** | **块内部结构**（我们的 encoder/注意力/门控 vs 标准 SDPA+FFN） |

**配置推导（同结构参数、同深度）**
- 我们 v6：`D=128, nh=8, mlp_mult=16, L=6` → N=256，每层 3×16×128² = 786K → **4.72M**
- 基线 TF：`D=256, nh=8, L=6` → 每层 (3+1+4+4)×256² = 786K → **4.72M**

⚠️ **诚实标注**：同结构参数 + 同深度约束下，**宽度必然不同**（v6 D=128 vs TF D=256），
因为两个架构的「参数-宽度-层数」关系不同。**这是架构固有差异的体现，不是不公平**；
但因此**总参不同**（词表税 ∝ D），会额外补一个「同总参」对照来排除容量碾压。

## 判据（主/辅，跑前锁死）
- **主判据**：**零样本生成的连贯性** —— 固定 prompt 前向生成，人读（TinyStories 论文的 GPT-4 打分范式可复用）
- **辅判据**：held-out val loss（**连续指标** —— 刻意避开离散 exact-match，防止「涌现幻象」；见 arXiv:2304.15004）
- **必报**：两边参数量表、实际 token 数、实际 epoch 数（≤4 epoch 硬规则）、墙钟时间
- **不做**：不拿 KL 蒸馏分当能力分；不对外称绝对能力

## 硬规则
- 同一份数据重复 **≤ 4 epoch**，日志记录实际 epoch 数
- 报结果时同时给 val loss（连续）+ 生成样本（人类可读），**缺一不可**
