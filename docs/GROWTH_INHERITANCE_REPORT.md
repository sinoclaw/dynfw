# Growth-inheritance 报告 —— warmstart 扩宽能否复用已学权重？（v0.0.1）

> 脚本：`experiments/scaling/growth_inheritance.py` · 数据：`results/v0.0.1/growth_inheritance.json`｜CPU 口径，3 seed，固定 val 集，同数据/同预算。

## 问题（爸爸问）
DynFW v0.0.1 是固定结构，100K → 更大要重头训练。**"能否从小模型 warmstart 扩宽到更大模型，复用已学权重"**——即"增量长大 + 复用"是否有戏。

## 设计（判据先行，一次一组变量）
- **A fresh-big**：D=96 从零随机，总预算 300 iter
- **B grow**：D=64 先训 150，**零填充扩宽到 D=96**（旧块精确继承、新块清零中性起跑），再训 150（总计 300）
- **C fresh-big-short**：D=96 从零只训 150（隔离"大模型短训"效应）

N=4*D，k=16，use_ffn=True，同数据/同 iters/同 seed，固定 val 集。

## 结果（3 seed，mean±std）
| 路径 | val | 说明 |
|---|---|---|
| **A fresh-big（300 it）** | **3.145 ± 0.004** | 最优 |
| **B grow（150小+150大）** | 3.314 ± 0.008 | 比 A 差 **+0.170** |
| C fresh-big（150 it） | 3.521 ± 0.024 | 预算不足，最差 |

## 结论（诚实、决定性）
**同总预算下，warmstart 扩宽（B）明显劣于目标规模重头训练（A），B − A = +0.170（std 只 0.004-0.008，方向稳定）。**

- **"增量长大 + 复用"在 DynFW v0.0.1 上不成立**：先把预算花在小模型、再扩宽继续训，**不如直接把大模型从零训满**。
- **机理（推测）**：小模型（D=64）学到的是**容量受限的解**；零填充扩宽后，新维度中性起跑，而 LayerNorm 覆盖全 D 会轻微重归一化，加上"先小后大"把训练预算中途切换，**反而偏离了直接在大模型上优化的轨迹**。小模型的已学权重**没有迁移出一套对更大模型更有用的表示**。
- **与 GSLM No-Go 同源印证**：GSLM 结论是"增长节点只加身份、能力落共享投影、隔离失败"；本实验进一步表明**即使做"权重继承式扩宽"，复用也拿不到增益**——**静态架构往上扩 = 重头训练**是常态，不是我们独有的坑（TF 亦然）。

## 边界
- 只在**单层 FusedFW + 一个扩宽步长（D64→D96）**测了；未测更深/更大步长/不同扩宽策略（如插值继承、learning-rate 重置）。但**结论方向（复用无增益、甚至有害）已清晰**。
- 本实验**不支持**"FusedFW 能越长越大复用"的说法——这应是未来做 growth 时的诚实边界。
